# Pavois

> Every surface, every mast.

Write an application once, in one vocabulary. It runs native on six
platforms — and its surfaces live wherever your network has room for them.

- One shared vocabulary: views, state, `@:surface` declarations
- Six native backends: SwiftUI · Compose · WinUI 3 · Qt/Silica · terminal · owner-drawn
- Surfaces beyond the window: covers, menus, settings, extra windows, remote panels
- A networked substrate: presence, transport, auth, fluidity — via cafos
